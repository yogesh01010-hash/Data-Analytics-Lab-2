## Dataset

The assignment specifies the Adult Income Dataset from the UCI Machine Learning Repository.

UCI source:
https://archive.ics.uci.edu/ml/datasets/adult

The notebook can automatically download the dataset if `adult.csv` is not already in the project folder. For GitHub submission, it is recommended to download the dataset and upload `adult.csv` to this repository as required by your instructor.

## How to run

1. Put `adult.csv` in the same folder as the notebook, OR allow the notebook to download it from UCI.
2. Open `Hands_On_Lab_2.ipynb` in Jupyter Notebook/JupyterLab.
3. Run **Kernel/Restart & Run All**.
4. Check the outputs for NumPy indexing, timing, filtering, round-trip verification and `value_counts()`.
5. Upload the notebook, Python file, dataset and generated output files to GitHub.

## Required lab tasks covered

1. NumPy arrays, field access, basic slicing and advanced indexing.
2. NumPy broadcasting and timing comparison against a Python loop.
3. Pandas filtering using three simultaneous conditions across three columns.
4. Groupby + aggregate, CSV/XLSX export, reload and verification.
5. `value_counts()` and class-imbalance/dominant-value analysis.
6. Short conclusion of approximately 150–200 words.
